HAND MOD — Fabric, Minecraft 1.21.1 (Java Edition)

КАК УСТАНОВИТЬ В ПРОЕКТ
1. Зайдите на https://fabricmc.net/develop/template/
   - Minecraft Version: 1.21.1
   - Mod Name: Hand Mod
   - Mod ID: handmod
   - Package Name: com.example.handmod
   - Отключите "Split client and common sources", "Data Generation" и Kotlin, если они включены.
2. Скачайте и распакуйте шаблон.
3. Удалите из шаблона папку src (или всё, что внутри src/main) и скопируйте сюда папку src из этого архива.
   (Если в шаблоне остался класс ExampleMod или mixins-файл — удалите их.)
4. Откройте проект в IntelliJ IDEA, дождитесь загрузки Gradle.
5. Запуск для теста:  ./gradlew runClient
   Сборка .jar:       ./gradlew build   -> build/libs/handmod-1.0.0.jar (не *-sources.jar)
   Положите .jar в папку mods вместе с Fabric API.

КАК ИГРАТЬ
- Скальпель: железный слиток над палкой.
- Игла с нитью: железный самородок + нитка (shapeless).
- Shift + ПКМ со скальпелем: отрезать руку (-3 сердца, слабость). Выпадает «Отрезанная рука».
  Сначала режется рука, которой вы НЕ держите скальпель, потом вторая.
- ПКМ с иглой (рука в инвентаре): пришить руку обратно (-1 сердце, тошнота).
  Иглу можно использовать даже без рук.
- Нет правой руки (для правши) = нельзя бить, ломать, ставить, использовать предметы основной рукой.
  Нет левой = нельзя использовать предмет во второй руке.
- После смерти руки отрастают.
